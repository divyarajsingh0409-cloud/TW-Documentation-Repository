# Source coverage and boundaries

The repository was prepared from the supplied class PDFs:

- `Lecture_1_TW`: LaTeX introduction, tools, source/output, compilation, structure, commands, comments, spacing, page styles, fonts, alignment and lists.
- `latex-Environments`: document classes, margins, headers/footers, title/abstract, heading styles, fonts, page background, lists, paragraph/page breaks and numbering; Beamer class overview.
- `LatexL2` and `Lmaths`: inline/display maths, fonts, relations, Greek letters, fractions, roots, sums/products/integrals, arrays, piecewise functions, equation alignment and matrices.
- `L-Tables`: basic tables, merged rows/columns, positioning, labels/references, sizing and colour.
- `L-Color-Figure-Picture`: text/math colours, predefined/custom colours, backgrounds/highlights, images, figure captions/references, rotation/cropping, side-by-side images and picture-environment drawings.
- `Doxygen`: Doxygen installation, workflow, comments/tags, class docs, diagrams, output formats, version control, Google Docs features and collaboration.
- `Git`: version-control concepts, local Git workflow, inspection/undo, GitHub remotes, push/clone/fetch/pull, branches, merge/conflicts, pull requests, forks, review, Issues, Projects, tags/releases and troubleshooting.

**Boundary:** The supplied Doxygen lecture covers both Doxygen and Google Docs. The Beamer material in the supplied set is part of the LaTeX environments lecture; this repository documents the class and demonstrates a small frame/overlay example. The supplied files do not establish a separate advanced Beamer syllabus, so none is claimed here. Examples are illustrative and are not copied lecture slide decks.
